## History rules

- Do not edit historical evidence to match current implementation.
- Add a short correction note when a historical statement is materially wrong;
  do not erase the original context.
- Move newly completed milestone plans here with a completion date and
  verification summary.
- Keep personal data, credentials, live paths, build artifacts, and executable
  binaries out of documentation history.
